# 电商一键生图与独立页面验收

日期：2026-09-19。范围：本地实现、单元回归、桌面浏览器和真实文字优化。未部署生产，未修改数据库结构或 Worker，保留原有部署改动及 9 月 16 日真实验收目录。

## 实现

- 默认只展示素材与商品描述，数量、费用与生成按钮始终可见。平台、风格、数量、图片模型、文字优化模型和分图编辑在高级设置中；可选调整方案和保存草稿。一键完成校验、上传、保存和提交。
- 创建会话采用客户端 UUID 幂等重放，创建任务保留原方案与请求 ID；提交复用任务卡的持久化请求协议与共享并发锁。保存成功、提交失败时展示已有任务，不新建任务重试。结果未知仍需核对。
- 草稿按用户、标签页、场景保存；附件复用共享缓存与 IndexedDB File 持久化。浏览目录或场景不创建服务端空会话，保存后迁移到真实会话。刷新恢复整套要求的编辑基线，保留逐图独立要求。
- App Router 使用 `/`、`/create`、`/create/[scene]`、`/sessions/[sessionId]`；`task`/`view` 定位任务与结果视图。共享工作区运行状态跨页面保留，旧场景查询参数替换跳转。
- 会话筛选为全部、普通创作、电商生图。聊天与普通生图合并，小红书归入电商；任务及当前草稿优先，不猜测标题。缺失元数据先查询任务，重命名合并保留分类，继续按更新时间排序。
- 描述进入完整提示词，缺少名称时生成内部标题。分图支持自动提炼、指定文案和不加文字；新商品主图默认无字，旧方案没有 textMode 时保留旧规则。
- 描述、卖点、标题、创作要求执行改写；名称、事实等仅整理格式。无变化不报成功、不新增撤销记录；保留取消、撤销、手工编辑后的建议确认及过期响应隔离。
- 面板采用父容器剩余高度，左右独立滚动，操作栏参与正常布局，不覆盖表单。

## 真实文字优化

用户在 Chrome 登录 `localhost:3141` 后，使用本地 HTTP 应用与真实模型、积分结算。没有绕过登录或计费。三次明确的浏览器验收请求合计 **0.20 积分**，不将当天其他流水计入本次样本。

| 模型 / 字段 | 原文摘录 | 实际结果 | 结算 |
| --- | --- | --- | --- |
| 豆包 / 商品描述 | “面料柔软，摸起来很柔软……日常通勤和周末出门都可以穿” | “这款奶油白针织开衫面料柔软，版型宽松，无论是日常通勤还是周末外出都适合，搭配裙子或裤子都很好看。” | 15:11:58，doubao，0.05 |
| 豆包 / 商品卖点 | “宽松的版型，穿着很自在；面料柔软，手感很软……” | “宽松版型，穿着自在；面料柔软，手感舒适；通勤、周末都可穿，搭配裙子、裤子都合适” | 15:13:04，doubao，0.05 |
| MiniMax / 商品卖点 | 同一段原始卖点 | “宽松版型，穿着自在；面料柔软舒适；通勤周末皆可穿，裙装裤装都好搭。” | 15:16:23，minimax，0.10 |

三个结果均实际回填并显示“已优化表达”。第二次原拟验证 MiniMax，但普通创作切回电商后恢复草稿原模型；核对界面价格和真实流水后确认仍为豆包，没有把它算作 MiniMax 通过。已在高级设置补充明确的文字优化模型选择，并验证选 MiniMax 时费用为 0.10、真实流水为 minimax。

最后读取可用积分 **7.36**、冻结 **0.30**、累计消费 **2.34**。历史未知图片结果仍保留，未新增真实图片调用；不能据 Mock 结果宣称真实一键图片生成或生产验收完成。
