# ZImage — light glass direction
Chinese ecommerce image creation workspace. Preserve all existing features, single composer, unified timeline and three official skills. User selected Apple-inspired light frosted glass: warm off-white canvas, translucent sidebar and composer, restrained blue emphasis, thin gray/white borders, soft shadows and system sans typography. No new branding, no decorative dashboards. Accessibility: clear text contrast, visible keyboard focus, 44px touch actions, reduced motion and reduced transparency fallbacks. Shared tokens apply to workspace, skills, login and account.
